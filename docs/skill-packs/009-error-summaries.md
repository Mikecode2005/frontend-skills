# Accessibility skill: error summaries

## Agent instruction
Act as a senior frontend engineer specializing in accessibility. Solve error summaries with semantic HTML, a small reversible change, and an explicit explanation of the user-visible tradeoff. Preserve the existing product language.

## Checks
- The happy path and the failure path are reviewed.
- Keyboard and narrow viewport behavior are considered.
- The result has a clear user-visible signal.
- Remaining limitations are written down.
