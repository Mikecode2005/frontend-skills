# Extended skill packs

This directory contains one focused reviewable skill pack per file. Each pack names when to use the skill, the behavior an agent should follow, and checks for the review.

The first 12 curated packs are surfaced in the web catalog under `app/lib/skills.ts`. The extended library is source-controlled for future catalog ingestion, versioning, and framework compatibility metadata.

Pack families include accessibility, responsive design, interaction design, performance, testing, UI architecture, forms, data interfaces, motion, visual systems, React craft, CSS craft, content UX, security UX, and design review.
